# ترجمهٔ فارسی فصل اول

فایل `Chapter1-fa.pdf` نسخهٔ بازنگری‌شدهٔ ترجمهٔ فارسی فصل اولِ `Chapter1.pdf` است.

- ۲۶ صفحه، با همان اندازه و ترتیب صفحات فایل اصلی
- ترجمهٔ فارسی و صفحه‌آرایی راست‌به‌چپ
- بازبینی مسئله‌ها، تمرین‌ها، فرمول‌ها و متن فصل
- استفاده از شکل‌های اصلی ورودی برای مکعب روبیک، شبکهٔ خلال‌دندان و درخت شمارش
- نمودارهای ون و شکل‌های ریاضی با برچسب‌های فارسی

نکته: فایل ورودی اسکن‌شده است و متن چاپیِ آن داخل تصویر صفحه قرار دارد؛ بنابراین ترجمه با استخراج لایهٔ متنی/OCR انجام شده و تصاویر اصلی در نسخهٔ نهایی حفظ شده‌اند.
